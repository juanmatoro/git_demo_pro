Recetario Casero

Sandbox para practicar Git con cosas reales

Bienvenida

Este recetario es el laboratorio practico del README de Git a Profundidad. Cada receta sirve como excusa para ejecutar un modulo del laboratorio: agregar archivos, hacer commits, ramificar, mergear, resolver conflictos, recuperar trabajo perdido y publicar versiones.

Para arrancar revisa la guia de practicas por modulo.

Por agregar

  • Bebidas (limonada, smoothie, te frio)
